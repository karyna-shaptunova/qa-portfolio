# E-commerce Website Testing Checklist

## 1. General Functionality
- [ ] Website loads correctly
- [ ] All pages are accessible
- [ ] No broken links (404 / 500 errors)
- [ ] Correct redirects are configured
- [ ] Page loading time is acceptable

---

## 2. User Interface (UI)
- [ ] Buttons are visible and clickable
- [ ] Fonts, colors, and styles match the design
- [ ] Images are displayed correctly
- [ ] Icons are recognizable and consistent
- [ ] Layout does not break on different screen sizes

---

## 3. Navigation
- [ ] Header navigation works correctly
- [ ] Footer links redirect to correct pages
- [ ] Breadcrumbs (if present) work properly
- [ ] Logo redirects to homepage
- [ ] Navigation order is logical and user-friendly

---

## 4. Product Catalog
- [ ] Product list is displayed correctly
- [ ] Product images load properly
- [ ] Product prices are displayed correctly
- [ ] Product descriptions are clear and readable
- [ ] Filters and sorting work correctly

---

## 5. Product Page
- [ ] Product details are accurate
- [ ] Product images can be enlarged
- [ ] Price matches catalog price
- [ ] Availability status is displayed correctly
- [ ] "Add to Cart" button works correctly

---

## 6. Shopping Cart
- [ ] Products are added to cart correctly
- [ ] Quantity can be increased/decreased
- [ ] Total price is calculated correctly
- [ ] Cart data is saved after page refresh
- [ ] Product can be removed from cart

---

## 7. Checkout Process
- [ ] Checkout page opens correctly
- [ ] Required fields validation works
- [ ] Error messages are clear and understandable
- [ ] Order summary is correct
- [ ] Confirmation message is displayed after order placement

---

## 8. Forms Validation
- [ ] Mandatory fields are marked
- [ ] Incorrect input shows validation message
- [ ] Email format validation works
- [ ] Numeric fields accept only numbers
- [ ] Special characters handling is correct

---

## 9. Cross-Browser & Cross-Platform Testing
- [ ] Website works in Chrome
- [ ] Website works in Firefox
- [ ] Website works in Safari
- [ ] Website works in Edge
- [ ] Mobile and tablet layouts work correctly

---

## 10. Usability & UX
- [ ] Interface is intuitive
- [ ] User can easily complete main actions
- [ ] Important elements are easy to find
- [ ] No misleading buttons or links
- [ ] Error messages guide the user

---

## 11. Security (Basic)
- [ ] Password fields are masked
- [ ] HTTPS is used
- [ ] Sensitive data is not visible in URL
- [ ] User session expires after logout

---

## 12. Regression Testing
- [ ] Fixed bugs are re-tested
- [ ] New changes do not break existing functionality
- [ ] Core user flows work after updates
