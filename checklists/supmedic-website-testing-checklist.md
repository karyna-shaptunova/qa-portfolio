# Website Testing Checklist – Supmedic

## Project
Supmedic medical company website  
https://supmedic.by

## Testing Type
Functional testing / UI testing / Usability testing / Cross-browser testing  
Testing method: Black-box testing

---

## 1. Functional Testing Checklist

- [ ] All navigation links work correctly
- [ ] Header menu links redirect to correct pages
- [ ] Footer links redirect to correct sections/pages
- [ ] No broken links (404 errors)
- [ ] Buttons perform expected actions
- [ ] Forms submit data correctly
- [ ] Required fields validation works properly
- [ ] Error messages are displayed for invalid input
- [ ] Pages load without functional errors
- [ ] Content corresponds to business requirements

---

## 2. UI Testing Checklist

- [ ] Buttons have consistent size, color, and style
- [ ] Text is readable and properly aligned
- [ ] Images are displayed correctly and not distorted
- [ ] No overlapping elements
- [ ] Correct font styles are used across pages
- [ ] UI elements are visually consistent
- [ ] Icons are recognizable and correctly placed
- [ ] Active and hover states are visible

---

## 3. Usability Testing Checklist

- [ ] Website navigation is intuitive
- [ ] User can easily find key information
- [ ] Logical order of elements in header and footer
- [ ] Clear call-to-action buttons
- [ ] Page structure is understandable
- [ ] Content is not overloaded or insufficient
- [ ] User expectations match actual behavior

---

## 4. Cross-Browser Testing Checklist

- [ ] Google Chrome
- [ ] Mozilla Firefox
- [ ] Safari
- [ ] Microsoft Edge
- [ ] Opera
- [ ] Yandex Browser

---

## 5. Cross-Platform & Responsive Testing Checklist

- [ ] Desktop resolution
- [ ] Tablet resolution
- [ ] Mobile resolution
- [ ] Layout adapts correctly on different screen sizes
- [ ] No horizontal scrolling
- [ ] Elements do not break on resize

---

## 6. Regression Testing Checklist

- [ ] Previously fixed bugs remain fixed
- [ ] No new bugs appear after fixes
- [ ] Core functionality still works after changes
- [ ] UI is not broken after updates

---

## 7. Content Testing Checklist

- [ ] Text content has no spelling errors
- [ ] Content matches page purpose
- [ ] Contact information is correct
- [ ] Links lead to relevant pages
- [ ] Information is clear and sufficient

---

## Notes
This checklist was created and used during manual testing of the Supmedic website.  
It helped identify navigation issues, UI inconsistencies, and usability defects.
