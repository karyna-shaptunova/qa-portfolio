# Bug Report: Incorrect Footer Navigation and Non-Working Links

## Bug ID
BR_SUPMEDIC_001

## Title
Footer links redirect to incorrect sections and contain non-clickable elements

---

## Environment
- Website: https://supmedic.by
- Browser: Google Chrome
- OS: Windows 10
- Device: Desktop
- Testing type: Functional testing / UI & UX testing
- Testing method: Black-box testing

---

## Preconditions
- User is on the main page of the website
- Page is fully loaded
- User is not authorized (public access)

---

## Steps to Reproduce
1. Open the website https://supmedic.by
2. Scroll down to the footer section
3. Click on footer navigation links (e.g. About Company, Projects, Vacancies, Contacts)
4. Observe the navigation behavior and page content

---

## Actual Result
- Some footer links redirect to incorrect sections
- Anchor names do not correspond to actual section titles
- One or more footer elements are not clickable
- Navigation logic in the footer is inconsistent and confusing for users

---

## Expected Result
- All footer links redirect to the correct corresponding sections or pages
- Anchor names match the actual content titles
- All footer elements are clickable
- Footer navigation follows a clear and logical structure

---

## Severity
Medium

---

## Priority
Medium

---

## Frequency
Always (100%)

---

## Impact
- User experience is negatively affected
- Users may have difficulty navigating the website
- Reduces overall usability and trust in the website structure
