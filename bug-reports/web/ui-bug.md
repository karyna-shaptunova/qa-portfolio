# BUG-02: Login button overlaps input field on mobile view

**Environment:**  
- Browser: Chrome (Mobile emulation)  
- OS: Windows 11  

**Steps to Reproduce:**
1. Open login page
2. Switch to mobile view
3. Observe login button position

**Actual Result:**  
Login button overlaps password input field

**Expected Result:**  
Login button should be displayed below input fields

**Severity:** Minor  
**Priority:** Medium
