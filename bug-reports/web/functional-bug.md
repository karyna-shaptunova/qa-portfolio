# BUG-01: User cannot log in with valid credentials

**Environment:**  
- Browser: Chrome 120  
- OS: Windows 11  

**Steps to Reproduce:**
1. Open login page
2. Enter valid username
3. Enter valid password
4. Click Login button

**Actual Result:**  
User is not logged in, error message is displayed

**Expected Result:**  
User should be logged in successfully

**Severity:** Critical  
**Priority:** High
